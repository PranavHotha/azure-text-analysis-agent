========================================================================
TEXT ANALYSIS & PII SANITIZATION AGENT - COMPLETE SETUP GUIDE
========================================================================

This guide walks you through setting up Azure AI Foundry cloud resources,
authenticating with Microsoft Entra ID, syncing agent instructions via the
Python SDK, and running the application.


------------------------------------------------------------------------
PART 1: AZURE AI FOUNDRY CLOUD CONFIGURATION
------------------------------------------------------------------------

1. Create a Microsoft Foundry Project:
   - Go to https://ai.azure.com and sign in with your Azure subscription.
   - Create or select a Foundry Project (e.g. text-analysis-project).
   - Copy your Project Endpoint from the project overview page.
     Example:
     https://<your-resource>.services.ai.azure.com/api/projects/<project-id>

2. Deploy the Model:
   - In the Foundry portal, navigate to Deployments (or Models).
   - Deploy gpt-4o (or gpt-4.1).
   - Note the deployment name (e.g. gpt-4o).

3. Create the Agent & Attach Azure Language Tool (Remote MCP):
   - In the left navigation, go to Build > Agents.
   - Create an Agent named: Text-Analysis-Agent
   - Select your model deployment: gpt-4o
   - Under Tools, connect "Azure Language in Foundry Tools" (MCP Server):
     Endpoint:
     https://<foundry-resource>.cognitiveservices.azure.com/language/mcp?api-version=2025-11-15-preview
     Authentication: Key-based (API key from your Foundry resource)
   - Under Agent Tools > Azure Language Tool > Configure:
     Set Approval setting to: "Always auto-approve all tools"
     Click Save.


------------------------------------------------------------------------
PART 2: LOCAL ENVIRONMENT SETUP
------------------------------------------------------------------------

1. Open your terminal in the agent directory:
   cd c:\<YOUR-WORKSPACE-PATH>\text-analysis-agent\agent

2. Create and activate a Python virtual environment:
   python -m venv labenv
   .\labenv\Scripts\Activate.ps1

   (Your terminal prompt will now show: (labenv))

3. Install required packages:
   pip install -r requirements.txt

   (Installs: python-dotenv, azure-identity, azure-ai-projects, streamlit)

4. Authenticate with Azure CLI (Microsoft Entra ID):
   Run this directly inside your IDE terminal (VS Code / PowerShell):
   
   az login

   What happens:
   - A browser window will automatically open asking you to sign in.
   - Sign in with the Azure account that has access to your Foundry project.
   - Once authenticated, close the browser tab.
   - The terminal will display your active subscription details.
   - You only need to run this command once; your login persists.

5. Configure .env file (Optional for Streamlit):
   Copy .env.example to .env:
   
   cp .env.example .env

   Open .env and set your project details:
   FOUNDRY_ENDPOINT="https://<your_foundry_resource_name>.services.ai.azure.com/api/projects/<your_foundry_project_id>"
   AGENT_NAME="<your_foundry_agent_name>"
   MODEL_DEPLOYMENT_NAME="<your_model_deployment_name>"

   Note: Configure your project details in `.env`. The web studio securely
   loads these settings on the server side without exposing them in the UI.


------------------------------------------------------------------------
PART 3: SYNC AGENT INSTRUCTIONS VIA SDK (ZERO PORTAL EDITING)
------------------------------------------------------------------------

Instead of manually editing system instructions in the web browser, push
the clean, line-free instructions directly to Azure using the SDK:

   python sync_agent.py

Result:
   [SUCCESS] Successfully updated 'text-analysis-agent' in Azure to version: XX


------------------------------------------------------------------------
PART 4: RUNNING THE APPLICATION
------------------------------------------------------------------------

Important: Always ensure your virtual environment is active in your terminal
(prompt shows: (labenv)), or call the environment's python path directly.

Option A: Launch Streamlit Web Studio (Recommended)
   With (labenv) activated:
      streamlit run app.py

   Or launch directly without activating:
      .\labenv\Scripts\python.exe -m streamlit run app.py

   Opens automatically in your browser at http://localhost:8501 (or 8502) featuring:
   - Text Analysis Agent: PII redaction, sentiment scoring, entity extraction.
   - Text Analysis Chat Assistant: Interactive chat with animated pulsing loader.
   - Interactive Sample Showcase: Verified benchmark cases with side-by-side results.

Option B: Launch Terminal CLI
   With (labenv) activated:
      python text-agent.py

   Or launch directly without activating:
      .\labenv\Scripts\python.exe text-agent.py

   Runs an interactive multi-turn conversation loop in the command line.


------------------------------------------------------------------------
PART 5: TROUBLESHOOTING & COMMON QUESTIONS
------------------------------------------------------------------------

1. Error: ModuleNotFoundError: No module named 'streamlit'
   Cause: You ran global python instead of the virtual environment.
   Fix: Activate the virtual environment first:
      .\labenv\Scripts\Activate.ps1
      streamlit run app.py
   Or run directly using:
      .\labenv\Scripts\python.exe -m streamlit run app.py

2. Error: Execution of scripts is disabled on this system (PowerShell)
   Cause: PowerShell script execution policy restriction.
   Fix: Enable script execution for your current terminal session:
      Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
      .\labenv\Scripts\Activate.ps1

3. Error: Azure Client is not connected / 401 Unauthorized
   Cause: You are not signed in or credentials are missing.
   Fix:
   - Run 'az login' in your IDE terminal, or sign in via Microsoft Entra ID in the web UI.
   - Ensure your Foundry Endpoint is set in your .env or session endpoint field.


------------------------------------------------------------------------
PART 6: MULTI-TENANT ENTRA ID (AZURE AD) AUTHENTICATION
------------------------------------------------------------------------

To enable "Sign in with Microsoft" so any user can use their own Azure
resources securely with temporary, short-lived tokens:

1. Register an App in Microsoft Entra ID (portal.azure.com):
   - Name: Azure-Text-Analysis-Agent
   - Supported Account Types: "Accounts in any organizational directory
     (Any Microsoft Entra ID tenant - Multitenant) and personal Microsoft accounts"
   - Redirect URI: Web -> http://localhost:8501 (and your live domain)

2. Add API Permissions:
   - Microsoft Cognitive Services / Azure AI Foundry -> user_impersonation (Delegated)

3. Add Client Secret (Optional for Confidential Clients):
   - Under Certificates & Secrets, create a new client secret.

4. Add to .env:
   ENTRA_CLIENT_ID="<your-app-registration-client-id>"
   ENTRA_TENANT_ID="common"
   ENTRA_CLIENT_SECRET="<optional-client-secret>"
   ENTRA_REDIRECT_URI="http://localhost:8501"

5. Launch Streamlit:
   Users will now see a branded "Sign in with Microsoft" button.
   Tokens are stored strictly in volatile session RAM and expire in 60 minutes.
